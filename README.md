# URL Shortener

A simple URL Shortener in Python using classes and JSON for persistent storage.  
Shortens long URLs to 5-character codes and allows retrieval of the original URL.

---

## Features

- Shorten long URLs
- Retrieve original URLs from short codes
- Save links in links.json so data persists between runs
- Menu-based interface

---

## Requirements

- Python 3.x (no external libraries needed)

---

## How to Run

bash
python url_shortener.py

Follow the menu instructions to shorten URLs or get original links.

---

## Notes

- Short codes are unique and automatically generated.
- JSON file stores all links (links.json by default).
